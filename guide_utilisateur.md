## 1. Connexion au système

### 1.1 Première connexion
1. Ouvrez votre navigateur et accédez à l'application
2. Entrez vos identifiants fournis par l'administrateur
   - Nom d'utilisateur
   - Mot de passe
3. Cliquez sur "Se connecter"

### 1.2 Mot de passe oublié
1. Cliquez sur "Mot de passe oublié"
2. Entrez votre adresse email
3. Suivez les instructions reçues par email

## 3. Gestion des employés

### 3.1 Ajouter un employé
1. Cliquez sur "Gérer les Employés"
2. Sélectionnez "Ajouter un employé"
3. Remplissez les informations requises :
   - Nom et prénom
   - Email
   - Date de naissance
   - Poste
   - Projet
   - Date d'embauche
   - Coordonnées
4. Cliquez sur "Enregistrer"

### 3.2 Modifier un employé
1. Recherchez l'employé
2. Cliquez sur l'icône de modification
3. Mettez à jour les informations
4. Sauvegardez les modifications

### 3.3 Supprimer un employé
1. Recherchez l'employé
2. Cliquez sur l'icône de suppression
3. Confirmez la suppression

## 4. Gestion des congés

### 4.1 Créer une demande de congés
1. Accédez à "Demandes de Congés"
2. Cliquez sur "Nouvelle demande"
3. Sélectionnez :
   - Employé
   - Type de congé
   - Dates (début et fin)
   - Commentaire (optionnel)
4. Soumettez la demande

### 4.2 Traiter une demande
1. Consultez la liste des demandes
2. Sélectionnez une demande
3. Choisissez :
   - Approuver
   - Refuser
   - Mettre en attente
4. Ajoutez un commentaire si nécessaire

### 4.3 Suivi des soldes
- Consultez les soldes par employé
- Vérifiez l'historique des congés
- Exportez les données

## 6. Rapports

### 6.1 Générer un rapport
1. Accédez à "Rapports"
2. Sélectionnez le type de rapport
3. Définissez les paramètres :
   - Période
   - Service/Projet
   - Type de congé
4. Générez le rapport

### 6.2 Types de rapports disponibles
- Statistiques d'absences
- Soldes de congés

- Synthèse par service
